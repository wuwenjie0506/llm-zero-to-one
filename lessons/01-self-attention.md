# 第 1 课：Self-Attention（自注意力）

> 本文是《Attention Is All You Need》(2017) 核心组件之一的自注意力笔记。
> 配套代码见 [`code/self_attention.py`](../code/self_attention.py)。

## 1. 一句话直觉

RNN 是「一个字一个字顺序读，只能记住前面的」；Self-Attention 是**让每个字同时「看」整句话里的所有字，并按『谁和我相关』加权聚合信息**。顺序不再是障碍，这就是它能并行、能抓长距离依赖的原因。

## 2. Q / K / V 是什么

每个 token 的向量 `x`，分别乘三个可学习的权重矩阵，得到三个向量：

| 向量 | 全称 | 比喻 |
|---|---|---|
| **Q**uery | 查询 | 「我现在在找什么」 |
| **K**ey | 键 | 「我能提供什么标签」 |
| **V**alue | 值 | 「我真正的内容是什么」 |

> 类比查字典：你要查的单词是 **Q**，字典里的词条是 **K**，词条的解释是 **V**。先用 Q 和每个 K 算「匹配度」，再按匹配度去取对应的 V。

```
Q = X · W_Q        K = X · W_K        V = X · W_V
```

`W_Q、W_K、W_V` 是模型要学出来的参数。

## 3. 核心公式

```
Attention(Q, K, V) = softmax( Q·Kᵀ / √d_k ) · V
```

三步拆开：

1. **算相关性**：`scores = Q · Kᵀ`，得到「每个 Q 对每个 K」的分数矩阵。
2. **缩放 + 归一化**：除以 `√d_k`（防止维度大时点积过大、梯度爆炸），再对每行做 **softmax**，变成「注意力权重」（每行加起来 = 1）。
3. **加权求和**：用权重去取 `V`，得到输出。

## 4. 手算例子（2 个 token，维度 d=4）

输入只有两个 token，`X = [[1,0,1,0],[0,1,0,1]]`。为了看清机制，先把 `W_Q = W_K = W_V = 单位阵`（真实模型里它们是学出来的）。

**Step 1 — 分数** `Q·Kᵀ = X·Xᵀ`：

```
        token1  token2
token1    2       0
token2    0       2
```

（token1 与 token2 的点积 = 0，说明它们「正交」、不相关。）

**Step 2 — 缩放**：`d_k = 4`，`√4 = 2`，每个分数 ÷ 2 → `[[1,0],[0,1]]`。

**Step 3 — softmax（逐行）**：

```
row1: [e^1, e^0] → [2.718, 1.0] → 归一化 → [0.731, 0.269]
row2: [e^0, e^1] → [1.0, 2.718] → 归一化 → [0.269, 0.731]
```

**Step 4 — 加权求和** `attn · V`：

```
输出行1 = 0.731·[1,0,1,0] + 0.269·[0,1,0,1] = [0.731, 0.269, 0.731, 0.269]
输出行2 = 0.269·[1,0,1,0] + 0.731·[0,1,0,1] = [0.269, 0.731, 0.269, 0.731]
```

**结论**：每个 token 的输出 = 「它关注的所有 token 的 V 的加权和」。这里两个 token 不相关，所以各自主要关注自己（0.731 自己、0.269 对方）。如果某两个 token 语义相关，它们的点积分数会变大，权重就会向对方倾斜——这就是「注意力」的来源。

## 5. PyTorch 代码

见 [`code/self_attention.py`](../code/self_attention.py)，核心就几行：

```python
Q = X @ Wq
K = X @ Wk
V = X @ Wv
d_k = K.size(-1)
scores = Q @ K.transpose(-2, -1) / (d_k ** 0.5)   # 缩放点积
attn   = F.softmax(scores, dim=-1)                 # 每行归一化
out    = attn @ V                                  # 加权求和
```

> 运行需要 PyTorch（`pip install torch`）。
