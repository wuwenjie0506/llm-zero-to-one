# 附：FFN 与神经网络 / CNN / RNN / Transformer 的关系与发展脉络

> 背景知识补充，用于理解「FFN 是什么、它和别的网络是什么关系」。

## 一句话总结

**FFN 就是最基础的那种神经网络（MLP）；CNN、RNN、Transformer 都是在这个「积木」上，为了对付不同问题改出来的结构变体。**

## 时间线

| 年代 | 网络 | 针对什么问题 | 核心创新 |
|---|---|---|---|
| 1958 | 感知机 | 分类 | 单个神经元 |
| 1986 | MLP（前馈网络 = FFN） | 通用 | 堆叠全连接层 + 反向传播 |
| 1989/2012 | CNN | 图像 | 卷积（局部 + 共享权重） |
| 1997 | LSTM/RNN | 序列（文字/语音） | 循环连接 + 门控 |
| 2014 | Seq2Seq + 注意力 | 翻译 | 注意力萌芽 |
| 2017 | Transformer | 序列，并行化 | 纯注意力 + FFN |
| 2018+ | BERT / GPT | LLM | 堆更大的 Transformer |

## 一步步拆解

### 1. FFN / MLP —— 最朴素的「积木」

一个 FFN 就是「**全连接层 + 非线性激活**」的堆叠：

```
输入 → 线性变换(矩阵乘法) → 激活函数 → 线性变换 → ... → 输出
```

「全连接」= 每个输入神经元和每个输出神经元**都连一条线**（每条线一个权重）。这是所有神经网络的**最小公分母**。

### 2. CNN —— 给 MLP 换一种「连接方式」来处理图像

问题：图像像素成千上万，全连接会爆炸（每个像素连每个神经元）。而且图像有「**局部性**」和「**平移不变性**」——一只猫在图的左上还是右下，都该被认出来。

解法：**卷积**。用一个小窗口（卷积核）在图上滑动，**局部连接 + 权重共享**，大幅省参数。

关系：**CNN = MLP 换了个更聪明的连接方式**。而且 CNN 的最后通常还会接几层全连接（MLP/FFN）来做分类——所以 **CNN 内部其实也有 FFN**。

### 3. RNN / LSTM —— 引入「时间/顺序」来处理序列

问题：文字是**有顺序的**（「我打你」≠「你打我」），MLP/CNN 都不天然处理顺序。

解法：**循环连接**——把上一时刻的输出再接回输入，一个词一个词地读。LSTM 再加门控，解决「读长了会忘」。

关系：**RNN = MLP 加上「循环」**。但循环没法并行，长序列还有梯度消失问题。

### 4. Transformer —— 用「注意力」取代循环，但保留 FFN

问题：RNN 太慢（不能并行）、长程依赖难。

解法（Attention Is All You Need）：**扔掉循环，用 self-attention 让每个词同时看所有词**。

关键点 👉 **Transformer 的每个 block 里，除了注意力，还有一个 FFN**：

```
Transformer Block = 注意力（词与词之间传递信息） + FFN（每个词内部加工）
```

所以 **FFN 不但没有被淘汰，反而成了 Transformer 的基本组件**——它就是从 MLP 一路传承下来的那个「全连接 + 激活」积木。

## 一图看懂关系

```
        神经网络（本质：可学习的线性变换 + 非线性激活）
                 │
        ┌────────┼─────────────────┐
        │        │                 │
       MLP      CNN              RNN
     (=FFN)   (图像专用)        (序列专用)
        │      连接方式=卷积     连接方式=循环
        │        └─── 也内含 FFN
        │
        └──────────►  Transformer
                        = 注意力(代替循环)
                        + FFN(传承自 MLP)
```

## 核心结论（记住这三句）

1. **FFN = MLP = 最基础的前馈神经网络**，是「全连接 + 非线性」这个积木。
2. **CNN、RNN 是给这个积木换了连接方式**（卷积 / 循环），去适配图像 / 序列。
3. **Transformer 用注意力取代了循环，但把 FFN 这个积木原样保留了下来**——Self-Attention 最终都要和一个 FFN 搭档，组成完整的 Transformer Block。
